VoicePrint — AI Text Humanization Pipeline

Multi-stage processing flow · All stages run locally except Adversarial Paraphrasing

Stages 1 & 4 — Free (Local)

  • Heuristic Scrub (Stage 1): 50+ regex rules that replace AI tells, force burstiness, break tricolon patterns, remove hedging — all pure Python
  • Style Polish (Stage 4): Dysfluency injection, passive→active voice, vocabulary variety, personal narrative hooks — zero dependencies beyond core

Stage 2 — API (One Provider)

  • Adversarial Paraphrasing: LLM generates N candidates via 3-level persona escalation (explain-to-friend, blog-style, rewrite from scratch)
  • PromptMemory: Tracks which escalation level produced lowest p_AI per session and biases future selections

Stage 3 — Detection & Selection

  • 3-tier ensemble: Statistical pre-filter (burstiness+patterns) → Perplexity (GPT-2) → RoBERTa (2 classifiers)
  • Best-of-N: Picks candidate with lowest p_AI score above similarity gate (≥0.68 to preserve meaning)
  • Retry Loop: If no candidate passes (p_AI ≥ 0.5), escalates prompt level and retries up to N times
